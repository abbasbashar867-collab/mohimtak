## النشر (على مشروع جديد فارغ)

### 1) Supabase
1. أنشئ مشروعاً مجانياً في supabase.com.
2. افتح **SQL Editor** والصق محتوى `supabase/install_all.sql` كاملاً ثم Run. (مرة واحدة فقط)
3. في **Authentication > Sign In / Providers**: عطّل "Allow new users to sign up" (التسجيل يتم من خادم الموقع)، واجعل الحد الأدنى لكلمة المرور 8.
4. من **Project Settings > API** انسخ: رابط المشروع، المفتاح العام (publishable)، المفتاح السري (secret).

### 2) GitHub
أنشئ مستودعاً **خاصاً** وارفع محتوى المشروع. ملف `.github/workflows/ci.yml` يبني الموقع ويشغل الاختبارات تلقائياً.

### 3) الاستضافة (Netlify)
خطة Vercel المجانية (Hobby) مخصصة للاستخدام غير التجاري، لذلك لا تناسب المنصة.
اربط المستودع في netlify.com، وأضف متغيرات البيئة:

| المتغير | القيمة |
|---|---|
| NEXT_PUBLIC_SUPABASE_URL | رابط المشروع |
| NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY | المفتاح العام |
| SUPABASE_SECRET_KEY | المفتاح السري (لا تشاركه مع أحد، ولا تلصقه في محادثة) |
| APP_URL | رابط الموقع الكامل، مثل https://example.netlify.app |
| TRUSTED_IP_HEADER | x-nf-client-connection-ip |
| CRON_SECRET | نص عشوائي 32 رمزاً أو أكثر |
| SETUP_TOKEN | نص عشوائي 24 رمزاً أو أكثر (مؤقت) |

### 4) المدير العام الأول
افتح `APP_URL/setup`، أدخل SETUP_TOKEN وبريدك وكلمة مرور من 14 رمزاً أو أكثر. **ثم احذف SETUP_TOKEN وأعد النشر.** لا توجد كلمة مرور افتراضية، ولا يمكن إنشاء مدير ثان.

### 5) حذف المستندات اليومي
في GitHub: Settings > Secrets and variables > Actions، أضف `APP_URL` و `CRON_SECRET`.

### التشغيل على حاسوب
```bash
cp .env.example .env.local   # ثم املأ القيم
npm install
npm run dev
```

## النسخ الاحتياطي والاستعادة
الخطة المجانية لا تتضمن نسخاً احتياطية تلقائية.
```bash
DATABASE_URL="postgresql://..." bash scripts/backup.sh
pg_restore --no-owner --dbname "$NEW_DATABASE_URL" backups/FILE.dump
```
- الملف يحتوي بيانات شخصية: احفظه مشفراً وخارج GitHub.
- صور Storage غير مشمولة وتُنسخ منفصلة.
- الاستعادة اختُبرت على PostgreSQL محلي فقط. جرّبها على مشروع Supabase تجريبي قبل الاعتماد عليها.

- تعديل المدير لبيانات المستخدم، وتعديل الإعدادات العامة والشروط من اللوحة.

## قرارات تفسيرية تحتاج تأكيدك
1. **الأزواج:** عميل مؤهل مقابل شركة مؤهلة؛ الزائد ينتظر. (البديل متاح من الإعدادات: أول زوج يفتح الأهلية للجميع)
2. **أساس العمولة:** العميل: رسوم أول بطاقة. الشركة: رسوم أول بطاقة + حصة المنصة من أول شحنة. (البديل: كامل الشحنة)
3. **مدة 7 أيام:** من تاريخ التسجيل؛ خلالها يستطيع المدير ربط حساب فاته الكود، وبعدها باستثناء موثق. لا تُقيّد مدة إكمال شروط النشاط.
4. **العمر:** لا يُطلب تاريخ الميلاد؛ المدير يؤكد 18+ من الهوية.
5. **الاسم:** يسجله المدير من الهوية عند الموافقة.
